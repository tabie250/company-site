# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「株式会社スカイライン・テクノロジーズ」の紹介サイトです。
`index.html` 一枚で完結するシングルページ構成で、以下のセクションを掲載しています。

- ヒーロー（キャッチコピー）
- お知らせ
- 会社概要
- 事業内容
- 開発プロセス
- 実績
- カルチャー
- お問い合わせ

## 開く方法

ビルドや依存パッケージのインストールは不要です。`index.html` を直接ブラウザで開くだけで表示できます。

1. このリポジトリをダウンロード、またはクローンする
2. `index.html` をダブルクリックして既定のブラウザで開く

もしくはターミナルから開くこともできます。

```bash
open index.html          # macOS
```

## 技術構成

- 素の HTML / CSS / JavaScript のみ（フレームワーク不使用）
- ライトモード / ダークモードの両方に対応
- ヒーロー背景のスカイラインは Canvas で描画
